# AgentSure

**Security for AI agents.** JANUS recovers the SPEC your AI agent should follow, tests it, and enforces it at runtime.

[Website](https://www.agentsure.tech) · [Platform](https://www.agentsure.tech/platform) · [Book a demo](https://www.agentsure.tech/contact) · [LinkedIn](https://www.linkedin.com/company/124373916)

## The JANUS platform

| Product | What it does | Stage |
|---|---|---|
| **JANUS Audit** | Recovers the business rules your agent should follow (the SPEC) from its code, prompts and tools, and tests every one. Also produces an AI-BOM: models, packages, tools and known vulnerabilities in one inventory. | Before go-live |
| **JANUS Pentest** | Simulated attacks on agents and their AI components: prompt injection, tool hijacking, MCP / A2A abuse. Reproducible evidence, not a score. | Before go-live |
| **JANUS Runtime Monitor** *(Early Access)* | Enforces the SPEC and guard rules on every live action: allow, block, escalate, log. | In production |

Available as **SaaS** or **on-premises**, for agents and code that cannot leave your environment.
