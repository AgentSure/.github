# AgentSure / .github

Organization-level GitHub configuration:

- `profile/README.md` — content shown on https://github.com/AgentSure
- `ISSUE_TEMPLATE/` — issue templates inherited by all repos that don't override
- `pull_request_template.md` — PR template applied org-wide
- `SECURITY.md` — security disclosure policy
- `workflow-templates/` — reusable GitHub Actions workflows offered when creating new workflows in any AgentSure repo

## Contributing

Templates here apply to every repo in the org. Change carefully, propose changes via PR, get one other Owner to review.
