# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in any AgentSure product, website or repository, please email **support@agentsure.tech** with the subject line `Security report`.

Please include:
- the affected product, URL or repository
- steps to reproduce
- the impact you observed

Please do not open a public GitHub issue for security reports.

We will acknowledge your report within 3 business days and keep you updated until it is resolved.
